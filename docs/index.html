How it is built

Knowledge base

Annual report, deck and call PDFs become page-cited markdown, tables and classified images.

Strategy gate

Each segment's economics and the valuation methods that fit are set and approved before any number.

Cited assumptions

Every driver carries a page reference and a confidence level, or is declared unsupported.

Three-statement model

A linked P&L, balance sheet and cash flow with a revolver; it must tie every year of every scenario.

Valuation

FCFF DCF on those cash flows, dated to the net-debt date, with a terminal value funded at the company's own return on capital.

Verification

Layout, type size, figure tracing and a check that no model output is typed into the prose; the Excel model is recalculated against every scenario.

One DCF everywhere. The report, the Excel model and this page compute the same value from the same cash flows. The Excel file is live formulas with a scenario switch, not a printout.
Calls are scored. Each rating is logged with dated falsifiers and a review date, and update notes score it against what happened.

Academic research project. Not investment advice. These reports demonstrate equity research methodology. They are not recommendations to buy, sell or hold any security and do not take account of any person's objectives. Figures come from company filings and other public sources and are dated to each report's cover date. The author holds no position in the securities discussed.
