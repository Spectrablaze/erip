Lease treatmentEBITDA is after Ind AS 116. Existing lease liabilities (INR 2,061 Cr) are deducted from enterprise value and new leases are charged as capex when signed (right-of-use additions, calibrated on FY26). This is equivalent to paying rent only if the lease discount rate equals the WACC; the incremental borrowing rate is not disclosed.yesThe weighted incremental borrowing rate from the lease note, and a check of the result against a pre-Ind AS 116 (rent-as-opex) DCF.

Return on new capital in perpetuity is set at 20%, equal to Trent's own FY25-FY26 ROIC (19.8%), an analyst decision rather than evidence about returns on stores not yet opened.
